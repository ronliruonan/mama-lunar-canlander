# 今日农历

面向 Android 桌面的离线农历小部件。当前已在 OnePlus MT2110、Android 14 上编译安装，并验证应用页面、桌面卡片添加和点击打开。

## 功能

- 农历月日（包括闰月）、公历与星期、干支生肖年。
- 当天节气，或下一节气及相隔天数。
- 春节、元宵、端午、七夕、中秋、重阳、腊八、除夕及带地域说明的小年。
- 默认 4×3 大字桌面小部件：农历 44sp 粗体、独立星期 30sp 中等字重、公历 18sp、节气 20sp；右上角手动刷新，点击卡片打开应用。
- 高对比度深浅色界面；全部历法计算在设备本地完成。

## 运行

使用 Android Studio 打开本目录，选择 USB 连接的手机，运行 `app`。

应用内的“添加到桌面”调用 Android 标准固定小部件请求。若桌面没有显示确认窗口，请长按手机桌面空白处，通过“小部件／窗口小工具”找到“今日农历”添加。

本次 OnePlus 真机的具体入口：长按桌面空白处 → Widgets（小部件）→ All（全部）→ 列表最底部的 Home screen widgets → 今日农历 · 节气 → 点击预览 → Done（完成）。原生 Android 小部件位于这个二级列表内。

## 父母使用的大字版

卡片分为三段：顶部完整公历和刷新按钮，中间居中的农历与完整星期，底部细分隔线及居中的节气。节气简写为“距秋分4天”或“今日秋分”；节日当天底部优先显示“今日中秋节”等，完整节气信息仍可在应用查看。文字不会为了塞入卡片自动缩小，也不会以省略号截断；长日期或系统大字体可能换行。

新添加的卡片默认 4×3。更新 APK 后，桌面通常会保留原有卡片的尺寸；建议长按旧卡片，把下边框向下拖高，或重新添加。日期换行或出现节日时需要更多空间。

## 时间与刷新

统一采用北京时间 `Asia/Shanghai`；干支年以春节换年，节气按整天显示。

小部件安排下一北京时间午夜的非精确闹钟，并使用 Android 小部件的 30 分钟周期更新补偿；重启、时间或时区调整、安装更新后重新计算。有卡片时才保留自定义闹钟，移除全部卡片后取消。应用打开和卡片刷新按钮也会更新全部实例。

省电、休眠、系统后台限制可能延迟刷新；不保证零点整点执行。用户在系统设置中强行停止应用后，应重新打开应用恢复工作。尚需真实过夜和省电条件下的长期验证。

## 主要代码

- `calendar/CalendarRepository.kt`：日期、节气和节日计算。
- `widget/LunarWidgetProvider.kt`：桌面渲染、点击和多实例刷新。
- `widget/WidgetRefreshScheduler.kt`：跨日调度和系统事件。
- `MainActivity.kt`：今日详情与添加卡片入口。
